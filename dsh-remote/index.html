DeepSeek Harness · 插件

在手机上
打开桌面 DSH

dsh-remote 给 DSH 桌面 Web GUI 加了一层局域网反向代理和登录门。手机或平板用浏览器打开后输入管理员密码， 看到的就是这台电脑上的那个 DSH。没有成员账号，也没有工作区隔离。

01 — 功能

代理与登录门

DSH 桌面壳只监听 127.0.0.1；插件在它前面放一个代理，负责转发与认证。

01

反向代理与登录门

随 DSH 启动，监听 0.0.0.0:3080 并转发到 127.0.0.1:52551。未登录先看到登录页，登录后写 30 天会话 Cookie，之后免登录。

02

窄屏自动换布局

远程视口 ≤900px 时叠加一层手机布局：侧栏变成抽屉，文件面板全屏，底部导航切换对话与文件。本机的桌面窗口不受影响。

03

上传与下载

「文件」标签里把文件拖到目录行即可流式上传，默认上限 512MB；预览标题栏的下载按钮可把原始产物取回手机，支持 Range。

02 — 界面

浏览器与安卓外壳

浏览器打开局域网地址即可使用；Android WebView 外壳多一层配对与原生登录。

03 — 安装

三步，然后重启

bundle 只在 DSH 启动时装配，所以装完必须完全退出再启动，不能只刷新页面。

01

装进 profile

用 DSH 自带的 CLI 安装（不要用全局 npm 里的旧版 dsh），或在 Plugin Manager 里执行 install_bundle。

dsh plugin --profile desktop add <本仓库路径>
02

确认装配顺序

profile 的 package.json 里，dependencies 和 dsh.profile.bundles 都要有 dsh-remote，且在 bundles 中排在 @deepseek-ai/dsh-web-app 之后。只有 dependencies 时包会装上，patch 不生效。

03

重启并登录

完全退出 DSH 再启动，手机打开 http://<电脑IP>:3080。默认账号 admin，密码 dsh-remote。

首次登录后

默认密码只是为了能进第一次。运行下面的脚本按提示输入新密码（隐藏输入），脚本会把 scrypt 哈希写进 %USERPROFILE%\.dsh\dsh-remote-auth.json，之后重启 DSH 生效。

scripts\set-remote-password.ps1

04 — 须知

它不做的事

这是一个单管理员插件，权限模型和桌面窗口完全一样。装之前请先看清这几条。

  • 没有成员隔离。登录者就是桌面操作者，可以读写 DSH 进程能访问的任意文件。
  • 目前是明文 HTTP。同一局域网内的嗅探者可能拿到会话 Cookie。网络不可信时请套 Tailscale 或在前置做 TLS。
  • 不做公网穿透。代理只监听本机的 3080 端口，不替你打洞。
  • 会话有边界。Cookie 为 HttpOnly、SameSite=Lax，签名绑定当前密码版本，改密码即吊销所有会话。
  • 启动 token 不下发。DSH 的启动 token 只留在代理进程内存里，不写日志、不进浏览器；上游 dsh-auth-* Cookie 在写回前被剔除。
  • 登录有速率限制。失败 5 次 / 10 分钟后按来源地址临时限速。
