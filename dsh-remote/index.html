DeepSeek Harness 插件

用手机打开
电脑上的 DSH

电脑上跑着 DSH，手机或平板连同一个 Wi-Fi，浏览器打开 http://电脑IP:3080， 输入管理员账号密码，看到的就是电脑上那个会话。插件本身是一个反向代理加一个登录页。

01 — 功能

它做了什么

把只监听 127.0.0.1 的 DSH 开到局域网，前面加一个登录页，再给手机补一套布局和文件传输。

01

反向代理与登录页

随 DSH 启动，监听 0.0.0.0:3080，转发到 127.0.0.1:52551。没登录先看到登录页，登录后写 30 天 Cookie，之后直接进。登录失败 5 次 / 10 分钟后按来源地址限速。

02

窄屏布局

远程浏览器视口 ≤900px 时换一套手机布局：左栏变抽屉，文件面板全屏，底部导航切换对话和文件。本机桌面窗口不受影响。DSH 升级导致内部锚点对不上时，自动退回桌面布局，页面照样能用。

03

文件上传与下载

「文件」标签里把文件拖到目录行，流式写入，默认上限 512MB。预览标题栏的下载按钮把产物取回手机，支持 Range。添加工作区时打开应用内目录浏览器，不用先在电脑上选。

03 — 安装

安装

装完必须完全退出 DSH 再启动。bundle 只在启动时装配，刷新页面不算。

01

装进 profile

用 DSH 自带的 CLI（resources\runtime\cli\bin\dsh.cmd），不要用全局 npm 里的旧版 dsh。也可以在插件管理器里执行 install_bundle。

dsh plugin --profile desktop add <本仓库路径>
02

检查 profile 配置

profile 的 package.json 里，dependencies 要有 dsh-remote，dsh.profile.bundles 里也要有，并排在 @deepseek-ai/dsh-web-app 后面。只有 dependencies 时包会装上，但 patch 不生效。

03

重启后登录

完全退出 DSH 再启动，手机打开 http://<电脑IP>:3080。默认账号 admin，密码 dsh-remote。

装完第一件事：改密码

默认密码只是为了能进第一次。运行下面的脚本，按提示输入新密码（不显示）， 哈希会写进 %USERPROFILE%\.dsh\dsh-remote-auth.json，重启 DSH 生效。 也可以直接在 profile 的插件配置里写明文账号密码，但不推荐。

scripts\set-remote-password.ps1

登录用的就是桌面那份权限，能读写 DSH 进程能访问的文件；服务本身是明文 HTTP，只在可信局域网里开。 要临时关掉，用远程访问面板里的暂停/恢复，它只停 3080 的代理，不卸载插件、不重启 DSH。

04 — 使用

装好之后怎么用

日常就三步。桌面窗口照常使用，手机布局只在远程窄屏时启用。

01

打开地址

手机浏览器输入 http://电脑IP:3080，登录一次，之后 30 天内免登录。换 Wi-Fi 或 IP 变了，重新输一下新地址即可。

02

加工作区

点「添加工作区」打开应用内目录浏览器：逐级进入、新建文件夹、直接选中当前目录。不用先在电脑上选好。

03

传文件

「文件」标签把文件拖到目录行上传；聊天框拖入也是走字节上传，不会插入本地路径。产物用预览标题栏的下载按钮取回。

05 — 排查

打不开的时候

这几个问题最常见，按顺序看一遍基本能定位。

手机打不开 http://电脑IP:3080
依次确认：手机和电脑在同一个网段；电脑上 DSH 正在运行；Windows 防火墙放行了 3080 入站；http://127.0.0.1:52551/api/remote/info 在本机能返回。局域网地址会自动跳过 169.254 开头的链路本地地址。
登录后马上又跳回登录页
会话签名绑定当前密码版本，改过密码或代理重启后旧 Cookie 会失效，重新登录一次即可。
手机上还是桌面布局
手机布局只在远程浏览器视口 ≤900px 时启用（粗指针设备放宽到 1180px），本机 127.0.0.1 窗口永远保持桌面布局。如果 DSH 升级后内部锚点对不上，插件会写入 data-dshm-caps 并保留桌面布局，页面仍然可用。
大文件上传失败
上传默认上限 512MB，超了会拒绝；目标目录还需要 DSH 进程有写权限。
换 Wi-Fi 后要不要改配置
不用。局域网地址每次请求从快照读取，默认 5 秒刷新一次，换网后直接用新地址访问。
