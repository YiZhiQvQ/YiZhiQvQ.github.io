DeepSeek Harness 插件

用手机打开
电脑上的 DSH

dsh-remote 让桌面版 DeepSeek Harness 可以通过局域网访问。在同一 Wi-Fi 下用手机浏览器打开 http://电脑IP:3080， 通过管理员登录后即可使用电脑上的会话。插件由反向代理、登录验证页面和窄屏适配三部分组成。

  • Windows 桌面版 DSH
  • 默认端口 3080

01 — 功能

主要功能

将原本只监听本机地址的 DSH 开放到局域网，加入登录验证，并为手机提供窄屏布局与文件传输。

01

反向代理与登录验证

随 DSH 启动，监听 0.0.0.0:3080 并转发到 127.0.0.1:52551。未登录时先显示登录页；登录成功后写入有效期 30 天的 Cookie，后续访问直接进入。同一来源 10 分钟内连续失败 5 次会被限速。

02

窄屏布局适配

远程浏览器视口宽度 ≤900px 时启用手机布局：侧栏改为抽屉，文件面板全屏显示，底部导航在对话与文件之间切换。本机桌面窗口保持原有布局；若 DSH 升级后内部锚点失效，会自动回退到桌面布局，页面仍可使用。

03

文件上传与下载

在「文件」标签中把文件拖到目标目录即可上传，采用流式写入，默认上限 512MB；预览标题栏的下载按钮可将产物取回手机，并支持 Range 断点续传。添加工作区时会打开应用内目录浏览器，无需先在电脑上选择路径。

界面展示

浏览器直接打开局域网地址即可使用；另有可选的 Android 外壳，提供二维码配对与原生登录。

03 — 安装

安装

安装完成后需完全退出并重新启动 DSH；bundle 仅在启动时装配，刷新页面不会生效。

01

安装到 profile

请使用 DSH 自带的 CLI（resources\runtime\cli\bin\dsh.cmd），不要使用全局 npm 中的旧版 dsh。也可在插件管理器中执行 install_bundle。

dsh plugin --profile desktop add <本仓库路径>
02

检查 profile 配置

在 profile 的 package.json 中，dependencies 与 dsh.profile.bundles 都要包含 dsh-remote，且后者中应排在 @deepseek-ai/dsh-web-app 之后。仅有 dependencies 时包会被安装，但补丁不会生效。

03

重启并登录

完全退出 DSH 后重新启动，在手机浏览器打开 http://<电脑IP>:3080。默认账号为 admin，密码为 dsh-remote。

安装后请先修改密码

默认密码仅用于首次登录。运行以下脚本并按提示输入新密码（输入时不显示）， 密码哈希会写入 %USERPROFILE%\.dsh\dsh-remote-auth.json，重启 DSH 后生效。 也可以在 profile 的插件配置中直接填写明文账号密码，但不建议这么做。

scripts\set-remote-password.ps1

登录后拥有与桌面会话相同的权限，可读写 DSH 进程能访问的文件；服务使用明文 HTTP，请仅在可信局域网内开启。 需要临时关闭时，可在远程访问面板中使用暂停／恢复，该操作只停止 3080 端口的代理，不会卸载插件或重启 DSH。

04 — 使用

日常使用

常用操作分为三步。桌面窗口保持原有方式使用，手机布局仅在远程窄屏下启用。

01

打开访问地址

在手机浏览器输入 http://电脑IP:3080，登录一次后 30 天内无需再次登录。更换 Wi-Fi 或电脑 IP 变化后，使用新地址访问即可。

02

添加工作区

点击「添加工作区」会打开应用内目录浏览器，可逐级进入目录、新建文件夹，或直接选中当前目录，无需预先在电脑上选择路径。

03

传输文件

在「文件」标签中把文件拖到目标目录即可上传；拖入聊天框同样按字节上传，不会插入本地路径。生成的文件可通过预览标题栏的下载按钮取回。

05 — 排查

常见问题排查

以下是最常见的问题，按顺序检查通常即可定位原因。

手机打不开 http://电脑IP:3080
请依次确认：手机与电脑处于同一网段；电脑上 DSH 正在运行；Windows 防火墙已放行 3080 端口的入站连接；本机访问 http://127.0.0.1:52551/api/remote/info 能正常返回。插件会自动跳过 169.254 开头的链路本地地址。
登录后马上又跳回登录页
会话签名与当前密码版本绑定，修改密码或重启代理后旧 Cookie 会失效，重新登录一次即可。
手机上还是桌面布局
手机布局仅在远程浏览器视口 ≤900px 时启用（粗指针设备放宽到 1180px），本机 127.0.0.1 窗口始终保持桌面布局。若 DSH 升级后内部锚点失效，插件会写入 data-dshm-caps 标记并保留桌面布局，页面仍可使用。
大文件上传失败
上传默认上限为 512MB，超出会被拒绝；此外目标目录需要 DSH 进程具备写权限。
换 Wi-Fi 后要不要改配置
不需要。局域网地址每次请求都从快照读取，默认每 5 秒刷新一次，换网后直接使用新地址访问即可。
